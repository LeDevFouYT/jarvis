Comment ça marche

  1. Téléchargez et lancez Jarvis-Installateur.exe. Il examine votre machine.
  2. Avec une carte : cliquez « Installer ». Sans carte : achetez le crédit, collez le jeton reçu, puis « Installer ».
  3. Double-cliquez Jarvis sur le Bureau et dites « Hey Jarvis ».
