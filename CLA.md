# Accord de contribution (CLA)

Merci de vouloir améliorer Jarvis. Avant qu'une proposition de code (pull request) puisse être fusionnée, son auteur
doit accepter cet accord. Il tient en une phrase : **vous gardez la propriété de ce que vous écrivez, et vous
m'autorisez à le distribuer, y compris sous licence commerciale.**

Sans cet accord, une seule ligne de code venue de l'extérieur empêcherait de vendre des licences commerciales,
puisqu'il faudrait l'autorisation de chaque contributeur pour chaque client.

## L'accord

En proposant une contribution au projet Jarvis (LeDevFouYT/jarvis), vous déclarez que :

1. **Vous en êtes l'auteur.** Le code est le vôtre, ou vous avez le droit de le donner. Il ne vient pas d'un employeur
   ni d'un projet qui vous l'interdit, et il ne contient pas de code copié sous une licence incompatible.
2. **Vous gardez vos droits d'auteur.** Vous restez libre d'utiliser votre code ailleurs, comme vous voulez.
3. **Vous accordez une licence large et définitive** à l'auteur du projet : le droit d'utiliser, reproduire, modifier,
   publier et distribuer votre contribution, **sous AGPL v3 comme sous licence commerciale**, sans limite de durée et
   sans contrepartie.
4. **Vous accordez les droits de brevet** que votre contribution nécessite, dans les mêmes conditions.
5. **Votre contribution est fournie telle quelle**, sans garantie.

## Comment l'accepter

Écrivez cette ligne dans le message de votre pull request, avec votre nom ou votre pseudo GitHub :

```
J'ai lu CLA.md et j'accepte l'accord de contribution. — @votre-pseudo
```

C'est tout. Une contribution sans cette ligne ne sera pas fusionnée, même si le code est excellent.

## Signaler un bug ou proposer une idée

Aucun accord n'est nécessaire : ouvrez simplement une issue. Les idées, les bugs et les retours sont les bienvenus
sans rien signer.
