# Licence commerciale

Jarvis est distribué sous **deux licences au choix**.

## 1. AGPL v3 — gratuite

C'est la licence du fichier [LICENSE](LICENSE). Elle convient si vous :

- utilisez Jarvis chez vous, autant que vous voulez, y compris pour votre travail ;
- le modifiez pour vous ;
- le partagez, le publiez, en faites une vidéo, un tutoriel, un fork.

Sa condition : **si vous distribuez Jarvis, modifié ou non, ou si vous le proposez à d'autres personnes à travers un
réseau (service en ligne, SaaS, bot hébergé), vous devez publier l'intégralité du code source de votre version sous
cette même licence AGPL v3**, y compris vos modifications et le code qui l'entoure.

## 2. Licence commerciale — payante

Elle existe pour les cas où l'AGPL ne convient pas, c'est-à-dire quand vous voulez :

- intégrer Jarvis dans un produit ou un service **sans publier votre code** ;
- le revendre, le distribuer sous votre marque, ou le livrer à vos clients ;
- l'héberger et le proposer en ligne à vos utilisateurs sans en ouvrir les sources ;
- un support ou des garanties.

Pour l'obtenir : ouvrez une demande intitulée « licence commerciale » sur
<https://github.com/LeDevFouYT/jarvis/issues>. Le tarif dépend de l'usage.
